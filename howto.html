肩X線計測 使い方

肩関節のX線画像に指標点を置き、AHI・CSA・LSA・DSA・GPA・RSA角、回転中心（骨頭中心・glenosphere 中心）の位置などを計算する研究・教育用の計測ツールです。

診断や治療方針の決定には使わないでください。画像と計測結果はこの端末の中だけに保存され、外部には送信されません。氏名などが写っている画像は切り取ってから取り込んでください。

1. 基本の流れ

  1. 画像を取り込む（スマホで撮った場合は「台形補正」）
  2. 症例ID（匿名）・側・分類・撮影方向を入れる
  3. 較正を設定する（mm で比較するため）
  4. 左の一覧の順にランドマークを置く（一部は「自動」で候補を置ける）
  5. 右の計測結果を確認し、気になる値はタップして画像上の位置を確かめる
  6. 「保存」。右上の「⋯」→「症例一覧」から CSV で書き出す

2. 画像の取り込み

上の「取り込み ▾」を押すと、次の方法を選べます。

  • 写真ライブラリ（iPhone・iPad）：写真ライブラリから選ぶ。HEIC もそのまま読めます
  • ファイル：ファイルから。PNG・JPEG（DICOM と HEIC は不可。PNG/JPEG に書き出してから）
  • カメラで撮影：モニターやフィルムをその場で撮影
  • 貼り付け：iPhone・iPad では写真アプリなどで画像を「コピー」してからボタンを押す。Mac ではスクリーンショットを ⌘⇧⌃4 でクリップボードに取り、⌘V
  • URL から：画像のアドレスから。サイトによっては取得できません
  • Mac では画像を画面にドラッグしても取り込めます
  • 「調整 ▾」の 左90°・右90° で回転、左右 で左右反転（プロット済みの点も一緒に動きます）
  • 「調整 ▾」の明るさ・コントラスト・白黒反転は表示だけを変えます。計測には影響しません
  • iPhone・iPad（縦向き）では画像が上に固定され、下の入力欄と計測結果だけがスクロールします

3. スマホで撮った画像の補正（台形補正）

  1. 「台形補正」を押すと、X線画像（フィルム・モニターの画像部分）の4隅を自動で探して黄色の点を置きます
  2. ずれていれば点をドラッグして直す。見つからないとき・置き直したいときは「手で置き直す」で4隅をタップ（縁の近くをタップすると角に吸着します）
  3. 縦横比が分かれば入力（例 35:43）。空欄なら、4隅の写り方から斜めに撮ったぶんを差し引いた本当の比を推定します
  4. 「適用」

モニターの外枠を拾うことがありますが、画面と同じ平面なのでゆがみの補正としては正しく働きます（余白が残るだけです）。縦横比の推定は、撮った写真をそのまま取り込んだときに最も正確です。トリミングした写真やスクリーンショットでは、比が分かっていれば入力してください。

撮影のコツ：モニターに正対し、画面いっぱいに大きく写す（レンズのゆがみは画面の中央ほど小さい）。照明の映り込みを避け、ピントを合わせる。較正は補正のあとで行います。

4. 点の置き方

  • 左の一覧で項目を選び、画像をタップすると点が置かれます。1点の項目は置くと次の未入力項目へ進みます
  • 複数点の項目（ピラー線・骨頭輪郭・肩峰下面・骨幹皮質など）はタップで点を追加し、終わったら「次へ」
  • 置いた点はドラッグで動かせます。動かしている間は拡大鏡が出ます
  • 画像の移動はドラッグ、拡大・縮小は2本指（ピンチ）またはマウスホイール。「全体」で元に戻ります
  • 「最後の点を消す」（⌘Z）、「この項目を消す」でやり直し
  • 分類（RSA 術後など）によって表示される項目が変わります

5. 自動検出

「自動」ボタンのある項目は、画像処理で候補を置けます。必ず目で確かめ、ずれた点はドラッグで直してください。

項目操作動き
SFL内側点・外側点を置いてから、外側点の「自動」2点の間の棘上窩底の線を探し、2点をその線上へ寄せる
ピラー線「自動」→ 外側縁の上を1回タップ外側縁の皮質を追って5点を置く（較正済みなら帯の中）
骨頭 輪郭「自動」→ 骨頭の中心付近を1回タップ輪郭を探して円を当てはめ、12点前後を置く
Glenosphere「自動」→ 中心付近を1回タップ金属の縁を探して点を置く
  • すでに点がある項目で「自動」を押すと、その点を手がかりにやり直します（タップ不要）
  • 自動で置いた点には輪が付きます。白＝確からしさ高、橙の破線＝要確認。一覧にも「自動」の印が出ます
  • 点をドラッグして直すと、手で確認した点として扱われ、印は消えます
  • 見つけられなかったときはメッセージが出ます。手動で置いてください

6. 較正（mm 換算）

  • Glenosphere 径から：RSA 術後。径（36・39・42 など）を入力し、glenosphere の輪郭を置く
  • 2点間の既知距離：較正マーカー球の両端など。較正 点A・B を置いて実距離を入力
  • mm/px 直接入力：DICOM の PixelSpacing ÷ 拡大率など
  • 較正しないと長さは px で表示されます。症例間の比較や基準症例の機能には較正が必要です

7. 計測結果

  • 必要な点がそろった項目から右側に表示されます
  • 項目をタップすると、画像上でその計測に使った線・角度・距離が黄色で強調されます。もう一度タップで解除
  • 「品質」は座標系の安定性の目安です。交差角 25° 未満、1点抜きの原点移動 2mm 超は ⚠ が出ます
  • 基準症例（同じ患者の術前など）を選ぶと、本来の関節窩に対するオフセットや、術前の骨頭中心からの移動量も出ます（両方とも較正が必要）

8. 座標系

  • X 軸 = SFL（棘上窩底線）、内側→外側が +
  • Y 軸 = SFL の垂線、頭側が +
  • 原点 = SFL とピラー線（肩甲骨外側縁）の交点。関節面から離れた位置で決まるため、OA の摩耗や術中のリーミングの影響を受けにくい
  • 比較用に旧来の原点（SFL × 関節窩線）も計算できます（画面下の「旧原点」）

角度の定義

  • CSA（Moor 2013）：関節窩線（上極−下極）と、下極→肩峰外側端の線のなす角。頂点は関節窩下極。肩甲骨の回旋・前後傾が少ない正面像（Grashey）で測る
  • LSA（Boutsiadis 2018）：肩峰外側端を頂点に、関節上結節への線と大結節最外側への線のなす角
  • DSA（Boutsiadis 2018）：関節上結節を頂点に、肩峰外側端への線と大結節最外側への線のなす角
  • LSA と DSA は同じ3点（関節上結節・肩峰外側端・大結節最外側）の三角形の角です。腕の外転・回旋で値が変わるため、下垂・中間位の正面像で測ります

目視分類（Hamada・Samilson・Walch・Favard・Sirveaux・Neer）は「見本」で模式図と定義を確認できます。

10. 保存・書き出し

  • 「保存」で端末内に保存。「⋯」→「症例一覧」から開く・削除・絞り込み。「⋯」には「新規」「使い方」もあります
  • 「CSV 書き出し」：全症例の計測値と点の座標（表計算ソフトで開けます）
  • 「バックアップ(JSON)」：画像を含む全データ。「読み込み」で別の端末へ移せます
  • iPhone・iPad では共有シートが開きます（「ファイルに保存」・AirDrop など）
  • アプリを削除すると保存した症例も消えます。定期的にバックアップしてください

11. よくある質問

点がずれる・指で見えない
拡大してから置くと正確です。点をドラッグすると拡大鏡が出ます。

AHI が出ない
「肩峰 下面（輪郭）」と「骨頭 輪郭（円）」の両方が必要です。

座標系が出ない
SFL の2点とピラー線（2点以上）が必要です。

自動検出がうまくいかない
コントラストの低い画像、肋骨が重なる外側縁、変形の強い骨頭では外れることがあります。手動で置くか、ずれた点を直してください。
